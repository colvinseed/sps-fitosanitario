HALLAZGOS SOBRE LA COPIA LOCAL — verificados el 30-07-2026
=============================================================================

1. NO INCLUIR ESTOS DOS ARCHIVOS EN EL COMMIT
   index.html  y  condiciones.json

   En la copia local de escritorio ambos estan con fin de linea CRLF de
   Windows, mientras que en el repositorio estan con LF:

       archivo             copia local        repositorio     delta
       index.html          769 CRLF           0 CRLF / 769 LF   +769 B
       condiciones.json    995 CRLF           0 CRLF / 995 LF   +995 B
       src/.gitignore        1 CRLF           0 CRLF /   1 LF     +1 B

   El delta de bytes coincide exactamente con el numero de lineas: el
   contenido es identico, solo cambia el fin de linea. Si se agregan al
   commit, se introduce una churn de fin de linea que pelea con el bot en
   cada corrida diaria. Los .py y template.html conservan LF.

2. git pull ANTES DE DESCOMPRIMIR
   El bot empuja sin pull previo. Trabajar sobre una copia atrasada hace
   rebotar el push.

3. daily.yml — REVISAR
   Ultimo commit de "SPS Daily Bot" (el que regenera index.html):
   2026-07-28 16:30 UTC. No produjo commit el 29 ni el 30 de julio.
   En ese periodo si corrio tablero.yml (commits "Condiciones actuales"
   de github-actions[bot]: 29-07 a las 00:14, 10:17, 20:16 y 23:46 UTC).

   Causa probable: carrera de push. daily.yml hace checkout, tablero.yml
   empuja en el intertanto, y el push de daily.yml se rechaza. daily.yml
   no tiene pull ni --rebase antes de push.

   Consecuencia practica: disparar "Run workflow" a mano puede fallar por
   la misma razon. Revisar la pestana Actions antes de darlo por hecho.
   No se modifico daily.yml: es pipeline de produccion y el ajuste no
   forma parte de este paquete.

4. src/.gitignore CONTIENE UNA REGLA INERTE
   Su contenido es  "output/"  con comillas literales. Git no interpreta
   comillas ahi: busca una ruta que contenga el caracter comilla. La regla
   no hace nada. Funciona de todos modos porque el .gitignore de la raiz
   tiene  output/  sin comillas, que calza a cualquier profundidad.
   No se corrigio: queda fuera del alcance de este paquete.
