NO INCLUIR EN EL COMMIT
=============================================================================
  index.html  y  condiciones.json
  En la copia local de escritorio ambos estan con CRLF de Windows, mientras
  que en el repositorio estan con LF. El delta de bytes coincide exactamente
  con el numero de lineas (769 y 995 respectivamente): el contenido es
  identico, solo cambia el fin de linea. Agregarlos genera churn contra el
  bot en cada corrida diaria.
  Por eso el git add es explicito por archivo. No usar  git add .

=============================================================================
PENDIENTE, FUERA DEL ALCANCE DE ESTE PAQUETE
=============================================================================
  daily.yml hace  git push  sin  pull --rebase  previo. tablero.yml empuja
  varias veces al dia, por lo que existe una carrera que puede rechazar el
  push de daily.yml. No se observo fallando el 30-07-2026 (corrida de las
  02:55 hora de Chile exitosa), pero la fragilidad sigue ahi. No se modifico:
  es pipeline de produccion.

  src/.gitignore contiene la regla  "output/"  con comillas literales, que
  git no interpreta como entrecomillado. La regla es inerte. Funciona de
  todos modos porque el .gitignore de la raiz tiene  output/  sin comillas.
